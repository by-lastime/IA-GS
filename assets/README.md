# IA'GS visual assets

`night-sky.png` is an original background generated with the built-in image-generation tool on 2026-09-24. It contains no museum artwork, artifact imagery, exhibition branding or UI text. Application controls and text are implemented in React/CSS, not baked into this image. Custom user backgrounds replace this local asset in the UI only.

Generation prompt:

> Create a standalone seamless-feeling deep night cosmic background asset for a restrained desktop productivity app. Landscape 1536x1024. Almost black midnight navy #070d18, very sparse tiny dim cold blue-white stars, exceptionally faint wispy blue galactic dust only along far right edge and bottom corners, center and upper-left nearly empty and very dark so app controls remain readable. Sophisticated and quiet, realistic astronomy texture but low contrast, no bright flare, no planets, no symbols, no text, no logo, no UI, no border. Overall 90 percent very dark negative space. Match dark cool blue starfield UI mood.

`app-icon.svg` and the generated app icons are IA'GS artwork. `screenshots/studio.png` shows the actual IA'GS interface with a synthetic project path; it includes no personal photos or models. Obsolete upstream marketing screenshots and logos have been removed from the current tree.
