# IA'GS v0.1.0 · 首个公开测试版

面向 **Apple Silicon、macOS 15+** 的本地照片 → 3D 高斯工作流。

## 下载

- **一般用户：** 下载 `IA-GS-0.1.0-macOS-AppleSilicon.dmg`，打开并将 IA'GS 拖入应用程序。
- **开发者：** 克隆仓库，运行 `npm ci`、`npm run setup:engines:macos`、`npm run start:app`。安装脚本校验并只读挂载 OOOSplat 官方安装器，仅提取依赖引擎；不安装或启动 OOOSplat。
- `SHA256SUMS` 提供 DMG 安装包的校验值。

安装包已包含照片助手、COLMAP、Brush 及所需动态库。普通用户只需下载 DMG，不需要另行下载引擎。此次公开发布源码、DMG 与校验文件，不单独发布引擎包。

## 本版功能

- Apple Vision 本地抠图，EXIF 方向、色彩和尺寸规范化。
- 前景重选、遮罩笔刷、照片复核与排除。
- 基于拍摄信息的相机分组；Plus / Pro 训练、可复用重建和真实训练百分比。
- PLY 预览、方向与缩放调整、裁切及导出。
- 命名任务、历史折叠与搜索、访达入口。
- 星空主题、四种配色、中英文和自定义本地背景。
- 无账号、无 API Key、无照片云端上传和遥测网络客户端。

## 测试状态与限制

- 本地 104 项前端测试、124 项 Rust 单元测试通过。
- 已完成真实 Plus 重建、Metal 实时进度短测、安装包完整性与启动检查。
- 完整 Pro 训练及更多设备、素材的覆盖仍需验证。
- 仅支持 JPG / JPEG / PNG；暂不支持视频、HEIC、RAW、Intel Mac、Windows 或 Linux。
- 玻璃反射、强高光、失焦和缺失视角不能靠抠图修复。生成模型不等于完整或可用于测量的三维记录。
- 安装包为 **ad-hoc 签名、未 Apple 公证** 的测试版。macOS 可能拦截从互联网下载后的首次启动；参照 [Apple 官方说明](https://support.apple.com/zh-cn/102445)，不要全局关闭安全保护。
